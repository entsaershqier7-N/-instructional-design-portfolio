# Instructional Design Portfolio

A complete portfolio with three end-to-end instructional design case studies and functional interactive learning prototypes.

## Live Portfolio
After enabling GitHub Pages, use the published site URL as the portfolio link on your resume and LinkedIn.

## Projects
1. **Phishing Defense** — scenario-based cybersecurity training.
2. **New Hire Launchpad** — first-30-days onboarding experience.
3. **Service Recovery Lab** — branching customer-service decision practice.

## Each project includes
- Case study
- Business/performance problem
- Audience analysis
- Measurable learning objectives
- Design document
- Storyboard
- Interactive HTML course
- Job aid/performance support
- Assessment strategy
- Evaluation plan

## Methods demonstrated
ADDIE, adult learning principles, Bloom's Taxonomy, scenario-based learning, microlearning, performance support, assessment design, and Kirkpatrick evaluation.

## Publishing with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this portfolio.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub to publish the site.

These are portfolio demonstration projects created to showcase instructional design skills.
